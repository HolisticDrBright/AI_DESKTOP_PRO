# Empty lab-range release store for fictional qualification

This CloudFormation candidate creates only a retained, versioned, private S3 bucket and its deny-only bucket policy in synthetic account `588966314750`. It does **not** create, sign, upload, approve or activate a lab-range release. It grants no writer or reader role, creates no object and does not change the owned-lab candidate or PHI posture.

The template is `infra/aws-clinical-core/qualification-lab-range-release-store.json`. It requires an existing reviewed KMS key ARN in `us-east-2`, the exact source commit and `PhiAllowed=false`. It pins the synthetic account, blocks public access, requires TLS and explicit SSE-KMS headers with the selected key, enables versioning and Object Lock, and retains the bucket across stack deletion or replacement. It has no lifecycle expiry because release removal and retention need a reviewed policy. Object Lock is enabled without an automatic retention period; this template alone does not make every uploaded version undeletable.

Before deployment, a reviewer must check the actual KMS key policy, bucket name availability, CloudFormation change set, ownership, retention implications, IAM for a separately governed uploader and the exact source commit. After deployment, inspect the real bucket policy, encryption, versioning, Object Lock, public-access block and lack of objects. Do not add a release until its primary-source verification, clinical holds, safety regression, signature and synthetic acceptance have been reviewed for the exact bytes. The current `lab-range-activation-readiness.md` says no real release has been prepared or signed and 70 hormone bands remain source verification `R`.

Local checks: three template-regression tests pass; `cfn-lint` passes; AWS `ValidateTemplate` accepts the template with three parameters. These are source and syntax checks, not a reviewed change set, deployed bucket, signed range release, positive hosted lab analysis or commercial/PHI evidence. Keep the owned-lab stack absent or blocked until its separate reviews and exact source/material bindings exist.
